# Control ERP

ERP for engineering, contracting and trading companies, by Control Contracting & Trading Company (Private) L.L.C.

| Folder | What it is | Build |
|---|---|---|
| [`desktop-v108/`](desktop-v108/README.md) | **Control ERP Desktop**: the complete v108 ERP (all modules) as a Windows program, with company data in a local SQLite file | `Build Control ERP Desktop (v108)` workflow → `Control-ERP-Desktop-Setup-<version>.exe` |
| [`erp/`](erp/README.md) | **The new platform**: business rules on a server, ready to grow into multi-user (Stage 2) and cloud (Stage 3) | `Build Windows installer` workflow (tags `v*`) |

The plan for Stages 1, 2 and 3, and how the two parts fit together, is in [desktop-v108/docs/ROADMAP.md](desktop-v108/docs/ROADMAP.md).

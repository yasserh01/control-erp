## List screens 

Most screens open as a list of records with a toolbar above it. 

_[Screenshot: A list screen: Purchase Orders with the toolbar and row buttons]_

A list screen: Purchase Orders with the toolbar and row buttons  + NewOpens an empty form to create a record. Search…Filters the list as you type. It looks in every field of the record, not only the visible columns. Status: AllShows only records with the chosen status (Draft, Approved, Posted, and so on). ClearRemoves the search text and status filter. Template / ImportOn master lists: download a blank CSV template with the right column headings, fill it in Excel, and import it to create many records at once. Excel / CSVExports the list to a CSV file that opens in Excel. PrintPrints the list as it is shown. RefreshRedraws the list with the latest data. Row buttonsEach row has buttons that depend on its status: Submit, Approve or Post, a conversion such as Convert to GRN, and Actions for everything else. Simple masters show Edit and Delete.

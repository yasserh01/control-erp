## First-time setup: the order that works 

The modules depend on each other. Setting them up in this order avoids empty drop-down lists and missing accounts later.  
- Company details. < Company Settings>>: name in English and Arabic, TRN, address, emirate and currency. These appear at the top of every printed document. 
- Company mode. < Company Mode>>: keep Single company unless you run several companies of a group in one system. 
- Chart of accounts and posting accounts. < Chart of Accounts>> → Load starter chart, then review < Account Mapping>> so each posting key points to a ledger. 
- Organisation. Branches, Departments, Designations, Cost Centres, Units, Currencies and Payment Terms in Master Data. 
- Banks and cash. Bank Accounts, Cash Boxes and Petty Cash Holders in < Masters & Settings>>. 
- Parties and items. Suppliers, Customers, Item Categories, Items, Service Items and Stores. 
- Projects. Projects, Cost Types, Job Heads, the Job Activity Master and BOQ budgets. 
- Manufacturing. Only if you build products: stores, option classes, specifications, product models, work centres, bills of material and routings. See the Manufacturing guide. 
- Marine Fleet. Only if you run vessels: create each vessel as a Fixed Asset, add the fleet accounts and roles in Settings, link the vessels, assign the crew and create the first voyage. See the Marine Fleet guide. 
- People. Employees (with documents, payroll details and the payroll category), Payroll Settings, Payroll Categories and Payroll Projects. 
- Time Management. If you track attendance: create the shifts and the public holidays, assign the shifts to the employees, create the time keeper roles in Settings & Roles and give them Time Management only. See the Time Management guide. 
- Extensions & API Hub. If you e-invoice in Saudi Arabia or the UAE, read attendance devices or bank statements automatically, or connect WhatsApp, e-mail or other services: load the demonstration data in a test company, add the extension, test it in simulation, and go live one connection at a time. See the Extensions & API Hub guide. 
- Opening balances. Opening balances on the chart of accounts, opening stock, the asset register and employee opening leave and EOSB. 
- Security. Create standard roles in < Role Permissions>>, add users, set approval rules, then turn on sign-in in < Login & Security>>. 
- Backup. Create the first backup and download the ZIP file. Turn on automatic backups.  

Where your data is keptThe ERP runs in your web browser and stores its data in that browser on that computer. Another computer or another browser starts empty. To move data, use < Backup Management>>: create a backup on one computer and import it on the other. Clearing the browser's site data deletes the ERP data, so keep downloaded backups somewhere safe.
